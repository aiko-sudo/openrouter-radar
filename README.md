# 模型雷达 — OpenRouterRadar

> 轻量 Android App：获取 OpenRouter 最新 / 免费 / 好用模型，带新模型提醒。

## 功能

- 直连 openrouter.ai 公共模型接口（无需 API Key）
- 视图：最新 / 免费 / 好用 / 全部 / 收藏，搜索、复制模型 ID、跳转详情
- 每卡片显示 输入/输出价格 与 周用量（Weekly Tokens）
- 下拉刷新；长按卡片可隐藏模型或加入不显示名单
- 新模型提醒：可选 2h / 6h / 24h 后台检查并通知，重启自动恢复
- 零第三方 UI 依赖

## 安装

从 [Releases](../../releases) 下载 APK 安装。打开即加载列表；顶部开关控制提醒与频率。
